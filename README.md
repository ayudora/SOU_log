# SOU｜制作ノート

制作の途中を、ちゃんと残す。写真・日付・短いメモを保存し、そのまま50mm角のシールへ配置するスマホ向けアプリです。

## 起動・GitHub Pagesへの配置

配布用のファイルは `index.html`、`style.css`、`app.js` の3つだけです。外部ライブラリ、ビルド、サーバーへの写真送信、アカウントはありません。

既存のGitHub Pagesリポジトリの任意のフォルダ（例：`production-note/`）に3ファイルをまとめて置けば、そのフォルダのURLから利用できます。相対パスなのでリポジトリ名に依存しません。既存アプリの上書きは必要ありません。今回は公開先リポジトリへの反映・デプロイは行っていません。

PCでは `index.html` を開いて画面を確認できますが、保存の動作はブラウザに依存するため、通常の利用・スマホでの利用はHTTPSのGitHub Pagesを推奨します。ローカルの動作確認例：このフォルダで `python -m http.server 8765 --bind 127.0.0.1` を実行して `http://127.0.0.1:8765/` を開きます。

## 基本操作

1. 「写真を撮る」または「写真を選ぶ」。メモだけでも記録できます。
2. 日付とひと言メモを入力。写真の切り取り位置は左右・上下のスライダーで調整します。
3. 「シールにする」でログを保存し、A4の最初の空きマスへ配置します。「ログに保存」なら後からまとめて配置できます。
4. 「シール・印刷」で任意のマスをタップしてログを選択。同じログを複数枚配置でき、使い終えたマスは空けておけます。
5. 最初に普通紙で「位置確認のテスト印刷」。合ったら「印刷・PDF保存」。印刷ダイアログを閉じても配置は残ります。

ログは後から編集可能。編集して保存すると配置済みの同じログにも反映されます。個別のPNG保存、全データのJSONバックアップと復元も用意しています。削除・配置の一括解除・復元による置き換えには確認があります。

## 寸法と印刷

- A4縦：210 × 297mm
- 50 × 50mm、横4 × 縦5、20面、隙間0mm
- 左5mm、上23.5mm（既存 `5cm_print` と同じ）
- 左右オフセット：−5〜＋5mm、上下：−20〜＋20mm、0.1mm刻み
- 全体倍率：98〜102%、0.1%刻み。左上を起点にマスの寸法・間隔を一緒に拡縮
- 用紙からはみ出す設定では印刷を無効化
- 通常印刷では枠・マス番号・操作UIを除外。テストでは20面の枠・中心・寸法と補正値を印刷

印刷設定はA4縦、実際のサイズ（100%）、ヘッダー・フッターなし、余白なし、プリンター側のふちなし拡大オフ。プリンターの非印字領域やブラウザの自動縮小はアプリから制御できません。50mmのテスト枠を定規で測り、カット済み用紙と重ねて確認してください。スマホから設定できない場合はPDFを実際のサイズで印刷できる環境を使ってください。実機のカメラ・AirPrint・プリンターでの用紙位置は別途確認が必要です。

## 保存と制約

- IndexedDBに写真・ログ・下書き・配置・調整値を保存します。同じ端末・ブラウザ・オリジン内でのみ復元され、端末間同期はありません。
- 写真は長辺1600px以内のJPEGへ変換。シールは800px角のPNGで統一し、画面と印刷の文字組みを揃えています。
- メモは最大80文字。写真ありの場合は印字可能な3行を超えると保存を止め、短くするよう案内します。自動改行で横のはみ出しを防ぎます。
- 保存容量不足・プライベートモード・ブラウザのデータ消去に備え、JSONバックアップを定期的に保存してください。保存失敗は画面に表示します。
- カメラボタンはスマホ標準の撮影画面を利用。端末によって写真選択画面が表示されることがあります。ブラウザが読めないHEICなどはJPEG等へ変換してください。
- オフラインPWA・複数ページへの自動分割・用紙規格の追加は未実装。1枚20面ごとに配置して印刷します。

## 参考アプリの確認と統合方針

2026-09-19に公開ページとHTML/CSS/JavaScriptを確認しました。参考コピーは `reference/` に保持し、配布用ZIPには含めていません。

| 観点 | 5cm_print | memo_log | 統合版 |
|---|---|---|---|
| 中心操作 | 20マスをタップし写真を選ぶ | カメラ・ファイル・テキストのみ | 記録→保存→配置→印刷を直結 |
| レイアウト | 50mm角4×5、左5mm・上23.5mm | 白余白つき800px角、写真3:2＋メモ＋日時 | 印刷寸法を維持し、共通の800pxシール画像を利用 |
| 写真調整 | object-fit:cover | 写真のドラッグ切り取り | 同じ3:2の切り取りを位置スライダーで調整 |
| 保存 | 表示中のみ | PNGのダウンロード＋表示中の一覧 | 端末内の下書き・ログ・配置の保存、再編集、PNG・JSON出力 |
| 日付 | なし | 保存時刻を自動描画、編集不可 | ローカル日付を自動入力、編集可 |
| メモ | なし | 改行ごとの描画、折返し・高さ制限なし | 自動折返し、日付領域を分離、超過時の案内 |
| スマホ | A4実寸の画面幅 | 最大400pxのシンプルなカード | 画面幅に合わせたA4縮小表示と大きな操作ボタン |
| 調整 | なし | なし | XY補正、倍率、普通紙でのテスト印刷 |

元アプリの軽い操作感・白い余白・落ち着いた色を残し、「画像を保存→別アプリで選び直す」をなくしました。コードは統合版として新しく作成しています。
