# SOU｜制作ノート — 名刺サイズラベル版

制作の途中を、ちゃんと残す。写真・日付・試作名・メモを、購入できる名刺サイズの粘着ラベルへ印刷します。

## 配布・GitHub Pages

`index.html`、`style.css`、`label-core.js`、`app.js` の4ファイルを同じフォルダに配置してください。ビルド・アカウント・外部ライブラリは不要です。既存のGitHub Pagesリポジトリの任意のサブフォルダでも動きます。旧版の3ファイルを更新するときは、追加の `label-core.js` も忘れずに配置してください。

ブラウザで写真を処理し、外部に送信しません。保存を安定して利用するためHTTPSでの利用を推奨します。この作業では公開リポジトリへの反映・デプロイは行っていません。

## 標準規格

| 項目 | 寸法・仕様 |
|---|---|
| 表示名 | A4 名刺サイズラベル 10面（91×55mm） |
| 補足表示 | A-one F10A4-1対応／2列×5段 |
| 用紙 | A4縦 210×297mm |
| 1片 | 横91×縦55mm |
| 面付け | 2列×5段、10面、列間・段間の隙間0mm |
| 余白 | 左右14mm、上下11mm |
| 原点 | 用紙の左上。1番は左14mm・上11mm |
| 最後の位置 | 10番は左105mm・上231mm |

寸法はA-one公式のF10A4-1製品仕様と面付け図で確認しました。
- [製品仕様](https://www.a-one.co.jp/product/search/detail.php?id=51002)
- [寸法図](https://www.a-one.co.jp/product/search/img/catalog/51002/format_O.jpg)
- [メーカーのテスト用PDF](https://www.a-one.co.jp/img_pdf/ZT51002_A.pdf)

F10A4-1は名刺カードでも使われる面付け規格であり、粘着シールであることを意味しません。購入する互換用紙は **粘着タイプ、91×55mm、2列×5段、左右14mm・上下11mm、隙間なし** を確認してください。サイズが同じでも余白や間隔が違う製品は、そのままでは対応しません。86.4×50.8mmの10面は別規格です。

## 撮る → メモする → ログシールにする → 印刷する

1. 写真を撮る／選ぶ。メモだけでも作れます。
2. 日付（自動入力・変更可）、タイトル・試作名（任意24文字）、メモ（80文字まで）を入力。
3. 貼る向きを横91×55mm／縦55×91mmから選択。写真の切り取り位置も調整できます。
4. 「ログシールにする」で記録を保存し、最初の空きラベルへ自動配置。「ログに保存」なら後からまとめて配置できます。
5. 印刷画面で任意のラベルをタップし、ログを配置。使用済みの位置は「使用済みにする」で除外できます。
6. 「今回印刷するラベル」のチェックを付けた位置だけ印刷。チェックを外しても配置は残ります。
7. 最初は普通紙でテスト印刷し、問題なければラベル用紙へ印刷します。

縦向きでは、貼った後に正立する55×91mmの内容を描き、時計回りに90度回転して91×55mm枠へ出力します。物理的な面付け・位置・ラベル枚数は横向きと同一。縦横のログを1枚のA4に混在できます。

横向きは上部に日付とタイトル、下部左に写真、右にメモ。縦向きは日付・タイトル・写真・メモを上から配置。全周3mmの内側余白を確保し、文字が収まらない場合は保存を止めて案内します。

## 使いかけ用紙と印刷調整

- 使用済みの位置は斜線で表示し、自動配置・通常印刷の両方から除外。指定時はその位置の配置だけ外し、ログ自体は保持します。
- 使用済み指定・配置・印刷チェックを端末内に保存し、再読み込み後も復元します。
- 印刷完了／キャンセルはブラウザから正確に判別できないため、使用済みへの変更は手動です。
- 「新しい用紙に切り替える」で配置・使用済み指定・印刷チェックをリセット。ログとプリンター補正値は保持します。
- XY補正は0.5mm刻み。右・下は＋、左・上は−。全体倍率98〜102%の補正も詳細内に残しています。
- A4の外へ出る設定・印刷対象ゼロでは通常印刷を無効化します。
- テスト印刷は選択や使用済み指定によらず、普通紙へ全10枠・中心線・寸法・補正値を出力。通常印刷には枠・番号・使用済み表示を含めません。
- A4縦、100%／実際のサイズ、ヘッダーとフッターなし、余白なし、ふちなし拡大オフで出力してください。アプリからプリンターの自動縮小や非印字領域は制御できません。
- 使いかけ用紙の再給紙は、用紙とプリンターの説明に従ってください。

## 保存と旧版からの移行

IndexedDBにログ・下書き・配置・用紙補正値を保存します。同じ端末・同じブラウザ・同じオリジン内だけの保存です。写真は長辺1600px以内へ縮小し、JPEG化。シール画像は1mmあたり12px（横1092×660px、縦660×1092px）です。

50mm角版の保存データを検出すると、全ログと下書きを保持して名刺サイズに変換します。配置と補正値は旧用紙専用なのでリセットし、画面に案内を出します。元データは同じ保存領域の `legacy-v1` キーへ退避します。旧版の改行が多く新枠に収まらないログは編集が必要と表示し、配置を止めます。本文は省略せず保持します。

PNG保存、JSONバックアップ・復元に対応。旧版JSONも読み込み可能です。ブラウザのデータ消去・保存容量不足に備えてバックアップを保存してください。端末間同期・オフラインPWA・20面への切り替え・自動複数ページ出力は含みません。

## 今後の用紙追加

`label-core.js` の `PAPER_PROFILES` に、用紙寸法・1片寸法・列数・段数・余白・隙間を集約。物理面付けの計算を内容の縦横レイアウトから分離しました。今回UIに出す規格は1種類だけです。

将来50×50mm、86.4×50.8mm、カスタムサイズを追加する際は、プロファイル定義に加え、用紙選択・保存データ検証と移行・サイズに応じた文字組みを拡張してください。規格を増やすだけでなく、各用紙の実機テストも必要です。

## 検証

`node check-v2.cjs` で寸法、回転、使用済み除外、選択印刷、文字数、旧データ移行を検証できます。ブラウザでの確認範囲と実機未確認事項は同梱の「確認結果.md」を参照してください。
