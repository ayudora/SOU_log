# 写真メモログ

撮る→メモする→ログに残す→印刷する

## 差し替え方法

この版は、ユーザー提供の `SOU-production-note-91x55` の7ファイルを基準に修正したものです。元フォルダは変更していません。

実行に必要なファイルは以下です。同じ配置でGitHub Pagesへアップロードしてください。

- `index.html`
- `style.css`
- `label-core.js`
- `app.js`
- `icons/` フォルダ全体（Font Awesomeの4アイコンとライセンス）

HTMLだけでなく、4ファイルとiconsフォルダを一緒に更新してください。更新後は再読み込みしてください。公開先の変更・デプロイは今回行っていません。

## 日付保存・印刷の追加修正

- 日付欄を消したときは、保存直前に空欄を読み取り、日付なしとして保存します。ブラウザの日付欄の検証状態だけで保存を止めないよう修正しました。
- 印刷位置ごとのチェックを廃止し、配置した写真メモをすべて印刷します。以前のチェック状態は読み込み時に破棄します。
- 印刷タブの数字と印刷枚数表示を削除。印刷した数や印刷履歴は保存しません。
- 「新しい用紙に切り替える」ボタンは残しています。

## これまでの変更

- アプリ名を「写真メモログ」に変更。その下に操作順を表示し、指定された詩的な文言を削除。
- 記録画面はプレビューを先に配置。PCでは左、650px以下の幅では上。
- 見出しを「記録」、入力項目名を「タイトル」に変更。
- 日付・タイトルは任意。日付は新規記録で当日を入力しますが、消しても保存・再編集・バックアップ復元できます。
- 画像内の日付・タイトル・本文は、空欄を飛ばして上から順に配置。タイトル1行のときは2行目の場所も空けません。
- 提供版の写真配置を維持。横向きは左の縦長写真（3:4）と右の文字、縦向きは写真の下に文字。
- ログ一覧はプレビューと同じ方眼背景・白い画像のカード。日付・タイトル・本文のテキスト重複を廃止。
- カードの下に印刷追加・編集・画像保存・削除のFont Awesomeアイコンを配置。操作領域は44px、読み上げ名とPC向けツールチップあり。
- 印刷画面の名称を「03 印刷」「写真メモを並べる」などへ変更。
- 用紙定義から選択肢・面数・寸法表示・配置・保存データ検証を生成。追加手順は `用紙レイアウトの追加.md` を参照。

## 維持した機能

91×55mm・A4の2列×5段、左14mm・上11mm・隙間なしの標準規格、縦横切り替え、写真の切り取り調整、使用済み位置の除外、配置した写真メモすべての印刷、位置と倍率の調整、テスト印刷、端末内保存、PNG保存、JSONバックアップ・復元を維持しています。

写真・タイトル・メモがすべて空の場合は保存しません。日付とタイトルの空欄だけが理由で保存を止めることはありません。文字が印刷枠からあふれる場合は案内を表示します。

## 既存ログと保存データ

保存先のIndexedDB名は旧版と同じです。同じブラウザ・同じオリジンの利用なら既存データを読み込めます。異なる端末・ブラウザ・ドメインへ移す際は旧版でJSONバックアップを保存して、新版で読み込んでください。

初回起動時に旧画像を新しい上詰め配置で再生成します。元の写真・日付・タイトル・メモ・ログIDを維持し、名刺サイズ版からの更新では使用済み位置・配置・補正値も保持します。更新前の保存データを同じ保存領域内の `before-photo-memo-v3` キーへ退避します。念のため、差し替え前に旧版の画面でJSONバックアップも保存してください。

新しい配置で文字が収まらない場合は、本文を保持したまま編集を促し、その画像を印刷対象から外します。50mm角の最初の旧版からの移行は、従来どおり用紙の違いにより配置・補正をリセットします。

## 印刷

最初に普通紙でテスト印刷し、用紙と重ねて位置を確認してください。A4縦、倍率100%／実際のサイズ、余白なし、ヘッダー・フッターなし、ふちなし拡大オフが基本です。プリンター側の自動拡縮や非印字領域はアプリからは制御できません。

実プリンター、iPhone/Android実機、PDFファイルとしての出力は未確認です。今回確認した範囲は `確認結果.md` に記載しています。
